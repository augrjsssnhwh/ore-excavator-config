## Overview

Terraria Ore Excavator Config provides a graphical configuration interface for the popular Ore Excavator SMAPI-style Terraria mod, allowing players to adjust the maximum vein size mined per swing, configure which block types trigger vein mining, set hotkey bindings, and tune performance limits without editing the mod's raw configuration file.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Ore Excavator Config** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Vein Size Limit** | Set the maximum number of blocks harvested per vein swing |
| **Block Whitelist** | Configure which block and ore types trigger vein mining behavior |
| **Hotkey Config** | Assign and rebind the toggle hotkey without editing config files |
| **Performance Cap** | Limit blocks per frame to maintain smooth framerate during mining |
